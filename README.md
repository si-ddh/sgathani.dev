# Personal Website

A modern personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

This website showcases my projects, technical interests, and experience as a Computer Science student at the University of Waterloo.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Vercel (deployment)

## Features

- Responsive layout
- Luxury black + purple theme
- Clean project showcase
- Smooth UI interactions
- Modern component-based architecture
